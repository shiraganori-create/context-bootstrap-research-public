# Context Bootstrap and Long-Horizon Behavior Research

Status: **Working research repository / Draft**

This repository collects research notes and external-communication materials concerning how initial context construction, bootstrap order, and long-horizon dialogue conditions can shape the effective behavior of an LLM session.

The current comparison has three main lines:

1. **Context Language Models (CLM)** — model-side editable context and context management.
2. **Discussion Oogiri / Two Dragons** — long-horizon dialogue in which persistent generative tendencies emerged from accumulated premises and interaction.
3. **Reader-State Oscilloscope A01–A04** — a bounded comparison series used to study how bootstrap order and context conditions are associated with diagnostic behavior.

## Working principle

We do **not** claim persistent learning or weight updates.  
The working question is narrower:

> To what extent does the construction and management of context function as part of the operational apparatus of an LLM session?

## Evidence discipline

Materials in this repository should distinguish:

- **SOURCE** — primary artifacts, prompts, outputs, papers, code, or fixed records.
- **OBSERVATION** — what can be directly identified from the sources.
- **INTERPRETATION** — hypotheses or explanations derived from those observations.

Internal canonical artifacts remain outside this repository unless intentionally exported for research communication.
