# 04 Comparative Analysis

## Working comparison

| System / case | Main context mechanism | Control locus |
|---|---|---|
| CLM | Editable context during execution | Model + harness |
| First Dragon | Context accumulated through long-horizon interaction | Human–model interaction |
| Second Dragon | Extracted operating instruction used as bootstrap | Human-designed bootstrap |
| Reader-State Oscilloscope A-series | Controlled source order, retrieval scope, and context environment | Human experimental design |

## Shared research interest

The common question is whether context should be treated as part of the experimental apparatus rather than as passive background.

## Non-equivalence warning

These systems are not equivalent and should not be collapsed into one claim. Similarity is useful as a comparison target, not as evidence of identity, priority, or shared mechanism.
