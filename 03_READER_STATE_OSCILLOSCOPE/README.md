# 03 Reader-State Oscilloscope A01-A04

This section compares four early Reader-State Oscilloscope runs. The sequence is not a scalar ranking.

A01 is an early baseline. A02 is the closed-context baseline. A03 reused the A02 bootstrap pattern inside an existing project context. A04 used a materially similar launch pattern in an isolated project.

The supported public claim is limited: different bootstrap and context conditions were associated with visibly different diagnostic structures. This is an observational association, not a single-variable causal proof.

Sampling counts, channel sets, display architecture, and environment differ across runs. More samples, channels, or visual detail must not be read as higher performance.
